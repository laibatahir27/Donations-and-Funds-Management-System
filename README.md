# 💰 Donations & Funds Management System

A desktop-based, fully functional management application designed and developed as a core **Software Construction (SC)** academic project. This system automates the process of tracking donations, managing donor databases, and auditing fund allocations to different relief sectors, following rigorous software engineering practices.

---

## 📋 Project Overview & Architecture

This project simulates a real-world NGO/Charity organization platform. Beyond just coding, the project involved complete lifecycle planning, including:
- **Requirement Engineering:** Detailed Software Requirement Specification (SRS) document defining functional and non-functional requirements.
- **System Design:** Architectural patterns and UML Diagrams (Use Case Diagrams, Class Diagrams, and Sequence Diagrams) to map data flow and object interactions.

---

## ✨ Key Features

- **Donor Management:** Add, update, view, and maintain records of donors with secure unique tracking IDs.
- **Fund Allocation Module:** Systematically allocate incoming funds to specific causes (e.g., Education, Healthcare, Disaster Relief).
- **Real-time Balance Sheet:** Dashboard showcasing total collected donations, total disbursed funds, and current available balance.
- **Receipt Generation:** Automated text-based transaction logs/receipts for donors upon successful contribution.
- **Secure Admin Login:** Restrictive access to the dashboard for system administrators to manage fund distributions.

---

## 🎨 User Interface & Logic

- **Frontend GUI:** Built using **Java Swing** and **AWT** components to provide a clean, user-friendly desktop experience.
- **Backend Logic:** Developed in **Java (OOP)** utilizing robust Exception Handling and File Handling (IO Streams) for persistent data storage of records.

---

## 🛠️ Tech Stack & Tools

- **Language:** Java (JDK 11+)
- **GUI Framework:** Java Swing & AWT
- **IDE:** Eclipse
- **Design Tools:** Draw.io / MS Visio (for UML Architecture & Diagrams)
